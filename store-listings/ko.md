# 한국어 (ko)

## Name
SpotRecall - AI로 다시 찾는 탭 자동 닫기

## Short description
사용하지 않는 탭을 안전하게 자동으로 닫습니다. 기억나는 내용을 설명하면 닫은 페이지까지 다시 찾을 수 있습니다. AI는 기기에서 실행됩니다.

## Detailed description
탭이 너무 많이 열려 있는데 하나도 닫기가 망설여지나요? SpotRecall은 사용하지 않는 탭을 닫고, 언제든 다시 찾을 수 있게 해 줍니다. 기억나는 내용을 설명하기만 하면 됩니다.

설치 직후 SpotRecall은 이미 열려 있는 탭을 색인한 뒤 12개로 정리합니다(개수는 직접 정할 수 있습니다). 닫힌 탭은 모두 48시간 목록에 표시되며, 클릭 한 번으로 다시 열 수 있습니다.

안전을 우선한 설계. 현재 탭, 고정 탭, 그룹 탭, 소리 재생 중인 탭, 양식을 입력한 탭은 절대 닫지 않으며, 모든 창에는 탭이 하나 이상 남습니다. 페이지는 닫히기 전에 색인되며, 브라우저가 이미 언로드한 탭은 제목과 URL이 보존됩니다. 최근 48시간 안에 닫힌 탭은 무엇이든 다시 열 수 있고, 툴바 팝업에서 언제든 자동 닫기를 끌 수 있습니다.

다시 여는 것을 넘어, 기억해 냅니다. Cmd/Ctrl+Shift+K를 누르고 정확한 키워드나 의미로 검색하세요. 키워드 검색은 오류 코드, URL, 버전 번호를 찾아 줍니다. 기기에서 실행되는 다국어 AI 모델은 막연한 설명만으로도 페이지를 찾아냅니다. 브라우저가 기기 내 Translation API를 제공하면 영어, 일본어, 중국어를 넘나들어 검색할 수 있으며, 그렇지 않으면 같은 언어로 검색합니다.

페이지 텍스트, 제목, URL, 시간 정보는 로컬 브라우저 데이터베이스에 저장됩니다. 페이지와 검색어는 절대 업로드되지 않습니다. 계정, 클라우드 동기화, 분석, 추적이 없습니다. 설치 시 SpotRecall은 열려 있는 탭과 북마크의 제목 및 URL을 색인하며, 이전 방문 기록은 가져오지 않습니다. 의미 검색은 약 135 MB의 공개 다국어 모델을 한 번 내려받아 로컬에 캐시합니다. 브라우징 데이터는 전송되지 않으며, 캐시 후에는 오프라인으로 작동합니다.

SpotRecall은 AGPL-3.0 오픈 소스입니다. 개인정보처리방침: https://github.com/dqj1998/SpotRecall/blob/main/PRIVACY.md
