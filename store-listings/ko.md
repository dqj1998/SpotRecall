# 한국어 (ko)

## Name
SpotRecall - AI로 검색하는 방문 기록

## Short description
의미나 키워드로 방문 기록을 검색하세요. AI는 기기에서 실행되며 페이지와 검색어는 기기를 떠나지 않습니다.

## What's new in 1.1.0
중요한 내용을 잃지 않고 탭을 정리하세요. 활성화하면 SpotRecall은 설정한 한도를 넘는 비활성 탭을 닫되, 색인된 페이지는 계속 검색할 수 있게 합니다. 활성, 고정, 그룹, 소리 재생, 저장하지 않은 양식이 있는 탭은 닫지 않으며 창을 비우지도 않습니다. 최근 48시간에 닫은 탭을 검토하고 다시 열 수 있습니다. 북마크 순위, 중복 결과 정리, 모델 다운로드 복구도 개선했습니다.

## Detailed description
브라우저 기록을 뒤지지 않고 기억나는 페이지를 찾으세요. Cmd/Ctrl+Shift+K로 정확한 키워드나 의미를 검색합니다.

SpotRecall은 오류 코드, URL, 버전 번호를 위한 키워드 검색과 기기에서 실행되는 다국어 AI 모델의 의미 검색을 결합합니다. Chrome 138+에서 기기 내 Translation API를 제공하면 영어, 일본어, 중국어를 넘나들어 검색할 수 있으며, 그렇지 않으면 같은 언어로 검색합니다.

선택적 자동 닫기로 탭을 정리하세요. 활성화한 뒤 설정한 한도를 초과할 때만 작동합니다. 색인된 페이지는 검색할 수 있습니다. 활성, 고정, 그룹, 소리 재생, 저장하지 않은 양식이 있는 탭은 보호되며 각 창에는 탭이 하나 이상 남습니다. 최근 48시간에 닫은 탭을 다시 열 수 있습니다.

페이지 텍스트, 제목, URL, 시간은 로컬 브라우저 데이터베이스에 남습니다. 페이지와 검색어는 업로드되지 않습니다. 계정, 클라우드 동기화, 분석, 추적이 없습니다. 설치하면 SpotRecall은 북마크와 열린 탭의 제목 및 URL을 색인하지만 이전 기록은 가져오지 않습니다. 의미 검색은 약 135MB의 공개 다국어 모델을 한 번 내려받아 로컬에 캐시합니다. 브라우징 데이터는 전송되지 않으며 캐시 후에는 오프라인으로 작동합니다.

SpotRecall은 AGPL-3.0 오픈 소스입니다. 개인정보: https://github.com/dqj1998/SpotRecall/blob/main/PRIVACY.md
