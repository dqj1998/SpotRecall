# 简体中文 (zh_CN)

## Name
SpotRecall - 自动关闭闲置标签页，用 AI 找回

## Short description
安全地自动关闭闲置标签页。描述你记得的内容，就能再次找到任何网页，包括已关闭的。AI 在你的设备上运行。

## Detailed description
标签页开得太多，却不敢关掉任何一个？SpotRecall 会关闭你没在用的标签页，并确保你随时都能把它们找回来。只需描述你记得的内容。

安装后，SpotRecall 会立即索引你已打开的标签页，并将其精简到 12 个（数量可自行设定）。每个被关闭的标签页都会出现在 48 小时列表中，一键即可重新打开。

安全设计。当前、固定、分组、正在播放音频以及填写了表单的标签页永远不会被关闭，每个窗口至少保留一个标签页。页面会在关闭前完成索引；浏览器已卸载的标签页会保留标题和 URL。最近 48 小时内关闭的任何页面都能重新打开，也可随时在工具栏弹窗中关闭自动关闭功能。

不只是重新打开，更能找回。按 Cmd/Ctrl+Shift+K，按精确关键词或按意思搜索。关键词搜索能找到错误码、URL 和版本号；在本机运行的多语言 AI 模型能根据模糊的描述找到网页。当浏览器提供端侧 Translation API 时，可在英文、日文和中文之间跨语言搜索；不可用时自动回退为同语言搜索。

页面正文、标题、URL 和时间戳都保存在浏览器本地数据库中。你的页面和搜索词绝不会上传。没有账号、云同步、分析或追踪。安装时，SpotRecall 会索引你打开的标签页以及书签的标题和 URL，不会导入过去的浏览历史。语义搜索会一次性下载约 135 MB 的公开多语言模型并缓存在本地。不会发送任何浏览数据；缓存后可离线使用。
