# What's New — 1.5.1 (all 21 locales)

Neither the Chrome Web Store nor Edge Add-ons has a "What's new" field. Append
the matching block as the last paragraph of each locale's description (after the
ContextWizard cross-promo paragraph), replacing the previous release's paragraph.

What else ships with 1.5.1 on the dashboard:

- **en, ja**: listing copy unchanged apart from the new ContextWizard paragraph;
  screenshots unchanged.
- **The other 19 locales** move to the 1.5.0 positioning ("Auto Tab Closer with
  AI Recall"): paste the full name / short / detailed description from
  `store-listings/<locale>.md` (the description replaces the old 1.3.1 text and
  its What's New), then append this file's block. The package's `_locales`
  carries the matching name and short description.
- **Their localized screenshots** are replaced with the full set of 5 from
  `release-screenshots/localized/<locale>/screenshot-1..5.png`, in that order
  (auto-close first). The 1.5.0 release held these back until the copy was
  updated, so the store should still show the pre-1.5.0 order: check, and
  replace all 5 slots, not only slot 1.

## en
What's new in 1.5.1: cleaner, more accurate search. Sign-in and security-check pages no longer pile up as separate entries, and they rank below the pages you are actually looking for. Text you type into a search or translate box that appears in the page address (for example, Google Translate) is now searchable, and typing no longer leaves one entry per keystroke. Your existing entries are tidied up once after the update.
