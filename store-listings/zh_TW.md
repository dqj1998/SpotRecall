# 繁體中文 (zh_TW)

## Name
SpotRecall - 自動關閉閒置分頁，用 AI 找回

## Short description
安全地自動關閉閒置分頁。描述你記得的內容，就能再次找到任何網頁，包括已關閉的。AI 在你的裝置上執行。

## Detailed description
分頁開太多，卻不敢關掉任何一個？SpotRecall 會關閉你沒在用的分頁，並確保你隨時都能把它們找回來。只要描述你記得的內容就行。

安裝後，SpotRecall 會立即為你已開啟的分頁建立索引，並將分頁精簡到 12 個（數量可自行設定）。每個被關閉的分頁都會出現在 48 小時清單中，按一下即可重新開啟。

安全設計。目前使用中、釘選、群組、正在播放音訊，以及已填寫表單的分頁絕不會被關閉，每個視窗至少保留一個分頁。頁面會在關閉前完成索引；瀏覽器已卸載的分頁會保留標題和 URL。最近 48 小時內關閉的任何分頁都能重新開啟，也可隨時從工具列的彈出式視窗關閉自動關閉功能。

不只重新開啟，更能找回。按下 Cmd/Ctrl+Shift+K，依精確關鍵字或依語意搜尋。關鍵字搜尋能找到錯誤碼、URL 和版本號碼；在裝置上執行的多語言 AI 模型能從模糊的描述找到網頁。當瀏覽器提供裝置端 Translation API 時，可以跨英文、日文和中文搜尋；無法使用時會自動回退為同語言搜尋。

頁面正文、標題、URL 和時間戳記都儲存在瀏覽器的本機資料庫中。你的頁面和搜尋詞絕不會上傳。沒有帳號、雲端同步、分析或追蹤。安裝時，SpotRecall 會為你開啟的分頁以及書籤的標題和 URL 建立索引，不會匯入過去的瀏覽紀錄。語意搜尋會一次性下載約 135 MB 的公開多語言模型並快取於本機。不會傳送任何瀏覽資料；快取後即可離線使用。
