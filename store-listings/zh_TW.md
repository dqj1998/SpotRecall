# 繁體中文 (zh_TW)

## Name
SpotRecall - AI 搜尋你的瀏覽紀錄

## Short description
依意思或關鍵字搜尋瀏覽紀錄。AI 在裝置上執行，頁面內容和搜尋詞都不會離開你的電腦。

## What's new in 1.1.0
新增「自動關閉分頁」：啟用後，當分頁超過你設定的保留數量，SpotRecall 會自動關閉閒置分頁；已收錄的頁面仍可搜尋。不會關閉目前、釘選、群組、播放音訊或含未儲存表單輸入的分頁，也絕不會關閉視窗最後一個分頁。可檢視並重新開啟最近 48 小時自動關閉的分頁。本版也改善了書籤與頁面中繼資料排序、重複結果合併，以及模型下載的驗證與重試。

## Detailed description
SpotRecall 幫你找回「明明看過」的網頁。依關鍵字或意思搜尋，使用 Cmd/Ctrl+Shift+K 隨時開啟。

SpotRecall 結合擅長錯誤碼、版本號和 URL 的關鍵字搜尋，以及在本機執行的多語言 AI 模型語意搜尋。當瀏覽器提供裝置端 Translation API 時，可以中英日任一語言搜尋另一語言的頁面；無法使用時會自動回退為同語言搜尋。

透過可選的自動關閉分頁保持整潔。僅在你啟用後且開啟數量超過保留數量時執行。已收錄的頁面仍可搜尋。目前、釘選、群組、播放音訊、含未儲存表單輸入的分頁不會被關閉；每個視窗至少保留一個分頁。最近 48 小時關閉的分頁可檢視並重新開啟。

頁面正文、標題、URL 和時間戳只存於瀏覽器本機資料庫，頁面內容與搜尋詞不會上傳。沒有帳號、雲端同步、分析或追蹤。安裝後，SpotRecall 會立即索引書籤與目前開啟分頁的標題和 URL，但不匯入過去的瀏覽紀錄。啟用語意搜尋時，會從公開模型主機一次性下載約 135 MB 的多語言模型並快取於本機。下載的只有公開模型檔案，不會傳送任何瀏覽資料；快取後可離線使用。
