# 日本語 (ja)

## Name
SpotRecall - 閲覧履歴をAIで検索

## Short description
閲覧履歴を意味やキーワードで検索。AIは端末内で動作し、ページ内容や検索語を外部に送信しません。

## What's new in 1.1.0
タブをすっきり保てる「タブ自動クローズ」を追加しました。オンにすると、設定した保持数を超えた非アクティブなタブを自動で閉じます。インデックス済みのページは SpotRecall で引き続き検索可能です。アクティブ、固定、グループ、音声再生中、入力途中のフォームがあるタブは閉じません。ウィンドウ最後の1枚も残し、直近48時間に閉じたタブは確認・再表示できます。検索順位、重複結果の整理、モデルのダウンロード復旧も改善しました。

## Detailed description
「さっき見たページ」を、ブラウザ履歴を掘り返さずに探せます。Cmd/Ctrl+Shift+K で、覚えている言葉や意味から検索できます。

SpotRecall は、エラーコード、URL、バージョン番号に強いキーワード検索と、端末内で動く多言語AIモデルによる意味検索を組み合わせます。Chrome 138以降で端末内 Translation API が利用できる場合は、英語・日本語・中国語をまたいで検索できます。利用できない場合は同一言語で検索します。

任意のタブ自動クローズでタブを整理できます。有効にした後、保持数を超えた場合だけ動作します。インデックス済みのページは検索可能なままです。アクティブ、固定、グループ、音声再生中、入力途中のフォームがあるタブは保護され、各ウィンドウには少なくとも1枚のタブを残します。直近48時間に閉じたタブは再度開けます。

ページ本文、タイトル、URL、時刻はブラウザ内のローカルデータベースに保存されます。ページ内容や検索語がアップロードされることはありません。アカウント、クラウド同期、分析、追跡はありません。インストール直後はブックマークと開いているタブのタイトル・URLを索引化し、過去の履歴は取り込みません。意味検索は公開の多言語モデル約135 MBを一度だけダウンロードしてローカルにキャッシュします。閲覧データは送信されず、キャッシュ後はオフラインで使えます。
