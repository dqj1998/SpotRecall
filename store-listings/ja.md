# 日本語 (ja)

## Name
SpotRecall - タブを自動で整理、閉じたページもAIで検索

## Short description
使っていないタブを安全に自動クローズ。閉じたページも、覚えている言葉で探し出せます。AIは端末内で動作し、データを外部に送信しません。

## Detailed description
タブが増えすぎても、閉じるのが不安ではありませんか。SpotRecall は使っていないタブを閉じ、閉じたページもいつでも取り戻せるようにします。覚えている言葉で探すだけです。

インストール直後に、開いているタブをインデックスしたうえで12枚まで整理します（枚数は変更できます）。閉じたタブは48時間の一覧に表示され、ワンクリックで開き直せます。

安心の設計。アクティブ、固定、グループ、音声再生中、入力途中のフォームがあるタブは閉じません。各ウィンドウには少なくとも1枚のタブを残します。ページは閉じる前にインデックスされます（ブラウザがすでに破棄したタブはタイトルとURLを保存）。直近48時間に閉じたタブは再度開けます。自動クローズはツールバーのポップアップからいつでもオフにできます。

開き直すだけでなく、思い出せる。Cmd/Ctrl+Shift+K で、キーワードでも意味でも検索できます。エラーコード、URL、バージョン番号はキーワード検索で正確に見つけ、端末内で動く多言語AIモデルがあいまいな説明からもページを探します。ブラウザで端末内 Translation API が利用できる場合は、英語・日本語・中国語をまたいで検索できます。利用できない場合は同一言語で検索します。

ページ本文、タイトル、URL、時刻はブラウザ内のローカルデータベースに保存されます。ページ内容や検索語がアップロードされることはありません。アカウント、クラウド同期、分析、追跡はありません。インストール時には開いているタブと、ブックマークのタイトル・URLを索引化し、過去の履歴は取り込みません。意味検索は公開の多言語モデル約135 MBを一度だけダウンロードしてローカルにキャッシュします。閲覧データは送信されず、キャッシュ後はオフラインで使えます。
