# What's New — 1.3.0 (all locales)

Neither the Chrome Web Store nor Edge Add-ons has a "What's new" field. Append
the matching block as the last paragraph of each locale's description, replacing
the previous release's paragraph.

---

## en
Your index now reminds you to back it up: once 50 pages have been added since your last export, the search panel shows a gentle prompt that takes you straight to Backup in settings — or dismiss it and it stays quiet. The search box also gained a clear button, so you can reset a query in one click instead of holding down backspace.
