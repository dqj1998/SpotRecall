# What's New — 1.3.1 (all locales)

Neither the Chrome Web Store nor Edge Add-ons has a "What's new" field. Append
the matching block as the last paragraph of each locale's description, replacing
the previous release's paragraph.

---

## en
Search results are more accurate. Filler words like "the", "of", 的 and の no longer drag in unrelated pages, weak semantic matches are filtered out instead of padding the list, and title-only entries such as backfilled bookmarks no longer outrank pages that really contain your words. Rows that look identical — same title, same preview — now collapse into one, and a query written only in Han characters is searched as both Chinese and Japanese, so it finds your pages either way.
