# What's New — 1.5.3 (all 21 locales)

Neither the Chrome Web Store nor Edge Add-ons has a "What's new" field. Replace
the 1.5.2 paragraph (the last paragraph of each locale's description, after the
ContextWizard cross-promo paragraph) with the matching block below.

The paragraph deliberately names no browser: Edge Add-ons warns "Avoid
referencing other browsers in your extension description such as Chrome", so
the same text is used on both stores.
