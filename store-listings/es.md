# Español (es)

## Name
SpotRecall - Cierre automático de pestañas y búsqueda con IA

## Short description
Cierre automático y seguro de pestañas inactivas. Encuentra cualquier página, incluso cerrada, describiéndola. IA en tu equipo.

## Detailed description
¿Demasiadas pestañas abiertas, pero te da miedo cerrar alguna? SpotRecall cierra las pestañas que no usas y se asegura de que siempre puedas recuperarlas. Solo tienes que describir lo que recuerdas.

Justo después de instalarlo, SpotRecall indexa las pestañas que ya tienes abiertas y las reduce a 12 (tú eliges el número). Cada pestaña cerrada aparece en la lista de 48 horas, donde un clic basta para reabrirla.

Seguro por diseño. Las pestañas activas, fijadas, agrupadas, con audio y con formularios rellenados nunca se cierran, y cada ventana conserva al menos una pestaña. Las páginas se indexan antes de cerrarse; las pestañas que el navegador ya ha descargado conservan su título y URL. Reabre todo lo que se haya cerrado en las últimas 48 horas y desactiva el cierre automático cuando quieras desde la ventana emergente de la barra de herramientas.

Recupera, no solo reabras. Pulsa Cmd/Ctrl+Shift+K y busca por palabra clave exacta o por significado. La búsqueda por palabra clave encuentra códigos de error, URL y números de versión. Un modelo de IA multilingüe que se ejecuta en tu dispositivo encuentra páginas a partir de una descripción aproximada. Cuando el navegador ofrece una Translation API local, puedes buscar entre inglés, japonés y chino; de lo contrario, busca en el mismo idioma.

El texto, título, URL y hora de las páginas se guardan en una base de datos local del navegador. Tus páginas y consultas nunca se suben. No hay cuenta, sincronización en la nube, analítica ni seguimiento. Al instalarse, SpotRecall indexa tus pestañas abiertas y los títulos y URL de tus marcadores; no importa el historial anterior. La búsqueda semántica descarga una sola vez un modelo público multilingüe de unos 135 MB y lo guarda en caché localmente. No se envían datos de navegación; una vez en caché, funciona sin conexión.
