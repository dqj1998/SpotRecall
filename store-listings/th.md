# ไทย (th)

## Name
SpotRecall - ค้นหาประวัติการท่องเว็บด้วย AI

## Short description
ค้นหาประวัติการท่องเว็บด้วยความหมายหรือคีย์เวิร์ด AI ทำงานบนอุปกรณ์ของคุณ และหน้าเว็บกับคำค้นจะไม่ออกจากอุปกรณ์

## What's new in 1.1.0
จัดระเบียบแท็บโดยไม่เสียสิ่งสำคัญ หลังเปิดใช้ SpotRecall สามารถปิดแท็บที่ไม่ใช้งานเกินขีดจำกัดที่ตั้งไว้ โดยหน้าที่จัดทำดัชนีแล้วยังค้นหาได้ ไม่ปิดแท็บที่กำลังใช้งาน ปักหมุด จัดกลุ่ม เล่นเสียง หรือมีฟอร์มที่ยังไม่บันทึก และไม่ทำให้หน้าต่างว่างเปล่า ตรวจดูและเปิดแท็บที่ปิดไปใน 48 ชั่วโมงล่าสุดอีกครั้งได้ ปรับปรุงการจัดอันดับบุ๊กมาร์ก การลบผลซ้ำ และการกู้คืนการดาวน์โหลดโมเดลด้วย

## Detailed description
ค้นหาหน้าเว็บที่คุณจำได้โดยไม่ต้องคุ้ยประวัติเบราว์เซอร์ ค้นหาคำที่ตรงตัวหรือความหมายด้วย Cmd/Ctrl+Shift+K

SpotRecall รวมการค้นหาคีย์เวิร์ดสำหรับรหัสข้อผิดพลาด URL และหมายเลขเวอร์ชัน เข้ากับโมเดล AI หลายภาษาบนอุปกรณ์สำหรับการค้นหาตามความหมาย เมื่อเบราว์เซอร์มี Translation API บนอุปกรณ์ คุณค้นหาข้ามภาษาอังกฤษ ญี่ปุ่น และจีนได้ มิฉะนั้นจะค้นหาในภาษาเดียวกัน

จัดระเบียบแท็บด้วยการปิดอัตโนมัติแบบเลือกใช้ ทำงานหลังเปิดใช้และเมื่อเกินขีดจำกัดเท่านั้น หน้าที่จัดทำดัชนียังค้นหาได้ แท็บที่กำลังใช้งาน ปักหมุด จัดกลุ่ม เล่นเสียง และมีฟอร์มที่ยังไม่บันทึกจะได้รับการปกป้อง และทุกหน้าต่างมีอย่างน้อยหนึ่งแท็บ เปิดแท็บที่ปิดใน 48 ชั่วโมงล่าสุดอีกครั้งได้

ข้อความหน้าเว็บ ชื่อ URL และเวลาจะอยู่ในฐานข้อมูลเบราว์เซอร์ภายในเครื่อง หน้าเว็บและคำค้นของคุณไม่ถูกอัปโหลด ไม่มีบัญชี การซิงค์คลาวด์ การวิเคราะห์ หรือการติดตาม เมื่อติดตั้ง SpotRecall จะจัดทำดัชนีชื่อและ URL ของบุ๊กมาร์กและแท็บที่เปิดอยู่ ไม่ได้นำเข้าประวัติเก่า การค้นหาตามความหมายดาวน์โหลดโมเดลสาธารณะหลายภาษาประมาณ 135 MB เพียงครั้งเดียวและเก็บในเครื่อง ไม่มีการส่งข้อมูลการท่องเว็บ และหลังจากนั้นใช้งานออฟไลน์ได้
