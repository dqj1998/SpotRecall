# ไทย (th)

## Name
SpotRecall - ปิดแท็บอัตโนมัติ พร้อมค้นคืนด้วย AI

## Short description
ปิดแท็บที่ไม่ได้ใช้อัตโนมัติอย่างปลอดภัย หาหน้าเว็บไหนก็เจออีกครั้ง แม้ปิดไปแล้ว แค่อธิบายสิ่งที่คุณจำได้ AI ทำงานบนอุปกรณ์ของคุณ

## Detailed description
เปิดแท็บไว้เยอะเกินไป แต่ไม่กล้าปิดสักแท็บ? SpotRecall จะปิดแท็บที่คุณไม่ได้ใช้ และทำให้มั่นใจว่าคุณเรียกกลับมาได้เสมอ แค่อธิบายสิ่งที่คุณจำได้

ทันทีหลังติดตั้ง SpotRecall จะจัดทำดัชนีแท็บที่คุณเปิดอยู่ แล้วจัดให้เหลือ 12 แท็บ (คุณเลือกจำนวนเองได้) แท็บที่ถูกปิดทุกแท็บจะแสดงในรายการ 48 ชั่วโมง ซึ่งเปิดกลับได้ในคลิกเดียว

ปลอดภัยตั้งแต่การออกแบบ แท็บที่กำลังใช้งาน ปักหมุด จัดกลุ่ม เล่นเสียง หรือมีฟอร์มที่กรอกค้างไว้จะไม่ถูกปิด และทุกหน้าต่างจะเหลืออย่างน้อยหนึ่งแท็บเสมอ หน้าเว็บจะถูกจัดทำดัชนีก่อนปิด ส่วนแท็บที่เบราว์เซอร์ยกเลิกการโหลดไปแล้วจะยังเก็บชื่อและ URL ไว้ เปิดสิ่งที่ปิดไปใน 48 ชั่วโมงล่าสุดกลับมาได้ และปิดใช้งานการปิดแท็บอัตโนมัติได้ทุกเมื่อจากป๊อปอัปบนแถบเครื่องมือ

ไม่ใช่แค่เปิดกลับ แต่ค้นคืนได้ด้วย กด Cmd/Ctrl+Shift+K แล้วค้นหาด้วยคีย์เวิร์ดที่ตรงตัวหรือด้วยความหมาย การค้นหาด้วยคีย์เวิร์ดช่วยหารหัสข้อผิดพลาด URL และหมายเลขเวอร์ชัน ส่วนโมเดล AI หลายภาษาบนอุปกรณ์จะหาหน้าเว็บได้จากคำอธิบายคร่าว ๆ เมื่อเบราว์เซอร์มี Translation API บนอุปกรณ์ คุณค้นหาข้ามภาษาอังกฤษ ญี่ปุ่น และจีนได้ มิฉะนั้นจะค้นหาในภาษาเดียวกัน

ข้อความหน้าเว็บ ชื่อ URL และเวลาจะอยู่ในฐานข้อมูลเบราว์เซอร์ภายในเครื่อง หน้าเว็บและคำค้นของคุณจะไม่ถูกอัปโหลด ไม่มีบัญชี การซิงค์คลาวด์ การวิเคราะห์ หรือการติดตาม เมื่อติดตั้ง SpotRecall จะจัดทำดัชนีแท็บที่เปิดอยู่ รวมถึงชื่อและ URL ของบุ๊กมาร์ก โดยไม่นำเข้าประวัติเก่า การค้นหาตามความหมายจะดาวน์โหลดโมเดลสาธารณะหลายภาษาขนาดประมาณ 135 MB เพียงครั้งเดียวและแคชไว้ในเครื่อง ไม่มีการส่งข้อมูลการท่องเว็บ และหลังแคชแล้วใช้งานออฟไลน์ได้
