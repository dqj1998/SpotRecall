# What's New — 1.2.1 (all locales)

Paste the matching block into the Chrome Web Store / Edge Add-ons dashboard
"What's new" field for each locale.

## en
More reliable auto-close: the "Tabs to keep open" limit could silently stop being enforced and never recover. It now repairs itself, and pages that cannot be indexed no longer block the limit. Closed tabs stay searchable by title, URL, and description. Search history now keeps 68 entries instead of 20, and the options page refreshes when you switch back to it.
