# Русский (ru)

## Name
SpotRecall - ИИ-поиск по истории браузера

## Short description
Ищите в истории по смыслу или ключевым словам. ИИ работает на вашем устройстве; страницы и запросы его не покидают.

## What's new in 1.1.0
Поддерживайте порядок во вкладках, не теряя важное. После включения SpotRecall может закрывать неактивные вкладки сверх заданного лимита, сохраняя доступность проиндексированных страниц для поиска. Он не закрывает активные, закрепленные, сгруппированные, воспроизводящие звук вкладки и вкладки с несохраненной формой, а также не оставляет окно пустым. Просматривайте и снова открывайте вкладки, закрытые за последние 48 часов. Улучшены ранжирование закладок, удаление повторов и восстановление загрузки модели.

## Detailed description
Найдите страницу, которую помните, не перебирая историю браузера. Ищите точное слово или смысл через Cmd/Ctrl+Shift+K.

SpotRecall сочетает поиск по ключевым словам для кодов ошибок, URL и версий с многоязычной моделью ИИ на устройстве для семантического поиска. Если Chrome 138+ предоставляет локальный Translation API, можно искать между английским, японским и китайским; иначе используется поиск на том же языке.

Упорядочивайте вкладки с помощью необязательного автозакрытия. Оно работает только после включения и при превышении вашего лимита. Проиндексированные страницы остаются доступны для поиска. Активные, закрепленные, сгруппированные, звучащие вкладки и вкладки с несохраненными формами защищены, а в каждом окне остается хотя бы одна вкладка. Повторно открывайте вкладки, закрытые за последние 48 часов.

Текст страницы, заголовок, URL и время остаются в локальной базе браузера. Страницы и запросы никогда не отправляются. Нет аккаунта, облачной синхронизации, аналитики или отслеживания. При установке SpotRecall индексирует заголовки и URL закладок и открытых вкладок, но не импортирует старую историю. Семантический поиск один раз загружает публичную многоязычную модель размером около 135 МБ и кэширует ее локально; данные браузера не отправляются, а после кэширования функция работает офлайн.

SpotRecall имеет открытый исходный код по AGPL-3.0. Конфиденциальность: https://github.com/dqj1998/SpotRecall/blob/main/PRIVACY.md
